# 🏋️ Apex Nutrition Generator

**Generador automático de planes de nutrición personalizados** basado en el **Biolayne Framework** + estructura **Built With Science**.

## 🎯 ¿Qué hace?

1. **Ingresa parámetros del cliente** (edad, peso, altura, % grasa, objetivo, actividad)
2. **Calcula automáticamente** TDEE y macros personalizados usando la ecuación Müller
3. **Ingresa un menú semanal** específico (desayunos, comidas, cenas reales)
4. **Genera automáticamente**:
   - ✅ Plan de comidas con macros ajustados al cliente
   - ✅ Recetas de meal prep basadas en los ingredientes del menú
   - ✅ Food charts organizados por macros
   - ✅ Lista de compras categorizada
   - ✅ **PDF exportable** para entregar al cliente

## 🚀 Como usar

1. **Tab 1 - Perfil Cliente:** Ingresa datos personales
2. **Tab 2 - Cálculos:** Ve los macros calculados
3. **Tab 3 - Menú:** Ingresa el menú semanal
4. **Tab 4 - Plan:** Ve el plan completo con macros distribuidos
5. **Tab 5 - Compras:** Lista de compras categorizada
6. **Tab 6 - PDF:** Descarga PDF personalizado

## 🧮 Fórmulas Biolayne Incluidas

- **BMR:** Müller Equation (edad, peso, % grasa)
- **TDEE:** BMR × Activity Factor
- **Macros:** Personalizados según objetivo (Pérdida Grasa / Ganancia Muscular / Mantenimiento)
- **Fibra:** ~12g por 1,000 kcal

## 📊 Base de Datos

Incluye ~40 alimentos:
- 🥚 Proteínas (9)
- 🌾 Carbohidratos (7)
- 🥦 Vegetales (6)
- 🍌 Frutas (5)
- 🫒 Grasas (6)
- 🧂 Condimentos sin calorías (13)
